Wi-Fi phone remote
  1. On the presentation laptop, double-click start-presenter.bat (or run: node server.mjs).
  2. Keep the terminal open. It prints the laptop's Phone URL, for example
     http://192.168.1.23:8787/remote.html.
  3. Connect the phone and laptop to the same Wi-Fi, open that Phone URL on the phone,
     and leave the remote page open. Use NEXT, PREV, FIRST, LAST, or any scene number.
  4. Open the deck from the same server URL (the printed Deck URL), not file://, so it
     can receive remote commands. A Windows Firewall prompt should allow Private networks.

The remote uses the local network only. If the phone disconnects, the laptop deck remains
fully controllable with its keyboard and on-screen controls.

If you see EADDRINUSE for port 8787, the first server is already running. Reuse the
Phone URL it printed; do not start a second copy. If you opened remote.html directly
as file://, close it and use the printed http:// Phone URL instead.
