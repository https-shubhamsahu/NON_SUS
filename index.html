// OPERATIONS PIPELINE

SYSTEM BLUEPRINT

Tactical execution flow of the NO SUS Zero-Knowledge protocol. Peer-to-peer confidentiality with zero server retention.

01
STATED

CLIENT-SIDE COLD MINT

Note text or file payload is encrypted directly in your browser using AES-GCM (256-bit). Key material and IV are appended to the URL hash fragment. The raw keys never touch our servers.

02
STATED

DECOUPLED DISPERSION

The encrypted ciphertext is stored in isolated Supabase databases and encrypted object storage. The index is mapped only to a UUID, with no identity logs or metadata association.

03
STATED

ATOMIC MINT CLAIM

When the recipient requests the note, the database record is atomically deleted at the moment of claim (SQL DELETE RETURNING). Two racing clients cannot claim the same secret.

04
STATED

FORENSIC WATERMARKING

For shared assets, Nox stands guard. The viewer enforces secure touch-to-reveal blur masks and stamps dynamic identifying details onto files to prevent document leaks.

Source Code
# A real Burn Note link, piece by piece:
https://nosus.foo/#/burn/<uuid>?k=<key>&v=<iv>
              │       │        │       │
              │       │        │       └─ 128-bit AES IV (32 hex chars)
              │       │        └─ 256-bit AES key (64 hex chars)
              │       └─ note id — the ONLY part the server knows
              └─ URL fragment: browsers never send anything after
                 "#" over the network, so the key and IV exist
                 only in your and your recipient's browsers.

# The ciphertext in the database is useless without the
# fragment — the server cannot decrypt what it stores.

THE SENTINELS

NO SUS employs a dual-mascot reactive system. Inside the workspace, Lux and Nox stand watch—their animation states responding dynamically to database read/write actions.

[ 01 ] LUX // LIGHT GUIDE

Onboarding counselor and study companion. Monitors background mint states and provides active feedback when jobs complete.

[ 02 ] NOX // DARK GUARD

Vault sentinel and seal guard. Nox triggers security overlays, alerts on suspicious actions, and manages document watermarking.
